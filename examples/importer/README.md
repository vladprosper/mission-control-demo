# Synthetic importer examples

All names, records, measurements and evidence in this folder are invented. The source names illustrate namespaces supplied by a user, not live connectors. The HTTPS example.org evidence is stored but never fetched.

- `records.json` and `records.csv`: equivalent two-record inputs; missing metrics versus observed zero clicks.
- `newer.json`: a newer scheduled snapshot for ART-101.
- `invalid.json`: valid first row followed by an invalid negative metric; neither row is written.
