What this demo actually implements

Python serves this interface and validates each story transition. SQLite holds the fictional story snapshots. Agent actions, Notion, manuscript changes, scheduled runs and platform observations are simulated. The separate technical lab runs the real JSON/CSV importer on synthetic fixtures.

The importer reports on records; it does not write back to Notion. No actual source is fetched and no AI model is called.
